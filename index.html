Interchange Sort (Sắp xếp đổi chỗ)

Bài thuyết trình nhóm – khoảng 10 người lần lượt trình bày

Cuộn xuống để bắt đầu

Từ ý tưởng

Ý tưởng cốt lõi rất thẳng: so sánh từng cặp phần tử và đổi chỗ ngay khi phát hiện chúng đứng sai thứ tự. Không cần chờ tìm phần tử nhỏ nhất như Selection Sort.

Với mỗi vị trí i từ 0 đến n−2, ta so sánh a[i] lần lượt với tất cả phần tử phía sau. Chỉ cần a[i] lớn hơn a[j] là đổi chỗ ngay.

Khác Selection Sort: Interchange Sort đổi chỗ ngay khi phát hiện, còn Selection Sort chờ tìm được min rồi mới đổi một lần.

Khi nào nên dùng / không nên dùng

Phù hợp khi học thuật toán cơ bản, mảng rất nhỏ, cần code ngắn. Không nên dùng dữ liệu lớn vì độ phức tạp O(n²). Chữ O dùng để đo thời gian chạy. O(n²) nghĩa là số lần so sánh khoảng n × n. Ví dụ 100 phần tử ≈ 10.000 lần so sánh.

✓ Phù hợp khi

  • Học thuật toán cơ bản
  • Mảng rất nhỏ
  • Cần code cực ngắn gọn

✗ Không phù hợp khi

  • Dữ liệu lớn
  • Cần ổn định
  • Swap (đổi chỗ) tốn kém

Thuật toán chi tiết

Bước 1: Cho i chạy từ 0 đến n−2.

Bước 2: Cho j chạy từ i+1 đến n−1 – so sánh a[i] với mọi phần tử đứng sau.

Bước 3: Nếu a[i] > a[j], đổi chỗ ngay a[i] ↔ a[j].

Bước 4: Lặp đến hết. Mảng đã sắp tăng dần.

1

Vòng ngoài

i: 0 → n−2

2

Vòng trong

j: i+1 → n−1

3

So sánh & Đổi

a[i] > a[j] → đổi ngay

4

Kết thúc

Mảng đã sắp tăng dần

Sơ đồ minh họa từng bước

Minh họa với mảng 5, 1, 4, 2, 8. i=0: đổi 5 với 1. i=1: đổi dần để số nhỏ lên trước. Cuối cùng: 1,2,4,5,8.

Ban đầu

Mã giả & Cài đặt C++

procedure InterchangeSort(a[0..n−1])   // bắt đầu thuật toán đổi chỗ
  for i ← 0 to n−2 do                  // vòng ngoài: vị trí đang xét
    for j ← i+1 to n−1 do              // vòng trong: mọi phần tử phía sau
      if a[i] > a[j] then              // nếu đứng sai thứ tự
        swap a[i] with a[j]            // đổi chỗ ngay
      end if
    end for
  end for
end procedure
void interchangeSort(int a[], int n) {   // hàm C++
  for (int i = 0; i < n - 1; i++) {      // i từ 0 đến n−2
    for (int j = i + 1; j < n; j++) {    // j duyệt phía sau i
      if (a[i] > a[j]) {                 // a[i] lớn hơn a[j]?
        int temp = a[i];                 // cất a[i] vào temp
        a[i] = a[j];                     // đưa a[j] lên vị trí i
        a[j] = temp;                     // đưa giá trị cũ ra sau
      }
    }
  }
}
procedure / hàm: bắt đầu Interchange Sort
for i: lần lượt cố định từng vị trí
for j: so sánh a[i] với mọi phần tử phía sau
if a[i] > a[j]: đứng sai thứ tự thì đổi ngay
temp: biến tạm để đổi 2 giá trị trong C++
Độ phức tạp: O(n²) — số bước ≈ n × n

Ưu điểm

Dễ hiểu, code ngắn, sắp xếp tại chỗ (in-place), phù hợp giảng dạy.

Nhược điểm

O(n²) — số bước ≈ n × n, đổi chỗ nhiều, không ổn định, ít dùng thực tế.

Kết luận

Interchange Sort đơn giản nhưng chậm với dữ liệu lớn vì O(n²). Nhóm em xin cảm ơn thầy cô và các bạn đã lắng nghe.
