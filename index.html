Interchange Sort (Sắp xếp đổi chỗ)

Bài thuyết trình nhóm

Từ ý tưởng

Ý tưởng rất thẳng: so sánh từng cặp và đổi chỗ ngay khi phát hiện đứng sai thứ tự. Không chờ tìm phần tử nhỏ nhất như Selection Sort.

Với mỗi vị trí i, ta so sánh a của i với mọi phần tử phía sau. Chỉ cần a của i lớn hơn a của j là đổi ngay.

Khi nào nên dùng / không nên dùng

Phù hợp khi học thuật toán cơ bản, mảng rất nhỏ, cần code ngắn dễ nhớ.

Không nên dùng dữ liệu lớn vì O(n²). Ví dụ một trăm phần tử khoảng mười nghìn lần so sánh. Cũng không phù hợp nếu cần ổn định, hoặc khi thao tác đổi chỗ rất tốn kém.

✓ Phù hợp khi

  • Học thuật toán cơ bản
  • Mảng rất nhỏ
  • Cần code ngắn gọn

✗ Không phù hợp khi

  • Dữ liệu lớn
  • Cần ổn định
  • Swap tốn kém

Thuật toán chi tiết

Bước 1: i chạy từ 0 đến n trừ 2.

Bước 2: j chạy từ i cộng 1 đến n trừ 1.

Bước 3: nếu a của i lớn hơn a của j thì đổi chỗ ngay.

Bước 4: lặp đến hết. Mảng đã sắp tăng dần.

Sơ đồ minh họa từng bước

Ví dụ mảng 5, 1, 4, 2, 8.

i bằng 0, giá trị 5 so với 1 thì đổi thành 1, 5, 4, 2, 8. i bằng 1 tiếp tục đổi dần. Cuối cùng được 1, 2, 4, 5, 8.

Ban đầu

Mã giả & Cài đặt C++

Hai vòng for lồng nhau. Bên trong chỉ một câu if. Nếu a của i lớn hơn a của j thì đổi chỗ.

Trong C++ dùng biến tạm temp: cất a của i vào temp, đưa a của j lên i, rồi đưa temp ra sau.

procedure InterchangeSort(a[0..n−1])   // bắt đầu thuật toán đổi chỗ
  for i ← 0 to n−2 do                  // vòng ngoài: vị trí đang xét
    for j ← i+1 to n−1 do              // vòng trong: mọi phần tử phía sau
      if a[i] > a[j] then              // nếu đứng sai thứ tự
        swap a[i] with a[j]            // đổi chỗ ngay
      end if
    end for
  end for
end procedure
void interchangeSort(int a[], int n) {   // hàm C++
  for (int i = 0; i < n - 1; i++) {      // i từ 0 đến n−2
    for (int j = i + 1; j < n; j++) {    // j duyệt phía sau i
      if (a[i] > a[j]) {                 // a[i] lớn hơn a[j]?
        int temp = a[i];                 // cất a[i] vào temp
        a[i] = a[j];                     // đưa a[j] lên vị trí i
        a[j] = temp;                     // đưa giá trị cũ ra sau
      }
    }
  }
}

Mô hình ví dụ – Sinh viên

Sắp sinh viên theo điểm tăng dần. Kết quả: Lê Văn C 6.8 → Nguyễn Văn A 7.5 → Trần Thị B 8.2 → Phạm Thị D 9.0.

Ưu điểm

Rất dễ hiểu, code ngắn, sắp tại chỗ không cần bộ nhớ phụ, phù hợp giảng dạy.

Nhược điểm

O(n²) nên chậm khi dữ liệu lớn. Số lần đổi chỗ thường nhiều hơn Selection Sort. Không ổn định. Ít dùng trong hệ thống thật.

Kết luận

Interchange Sort đơn giản nhưng không hiệu quả với dữ liệu lớn. Nên học để hiểu cơ chế đổi chỗ. Nhóm em xin cảm ơn thầy cô và các bạn.
