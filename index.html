Interchange Sort (Sắp xếp đổi chỗ)

Bài thuyết trình nhóm – khoảng 10 người lần lượt trình bày

Cuộn xuống để bắt đầu
01 · Người trình bày 1

Từ ý tưởng

Đọc to

Ý tưởng cốt lõi rất thẳng: so sánh từng cặp phần tử và đổi chỗ ngay khi phát hiện chúng đứng sai thứ tự. Không cần chờ tìm phần tử nhỏ nhất như Selection Sort.

Với mỗi vị trí i từ 0 đến n−2, ta so sánh a[i] lần lượt với tất cả phần tử phía sau. Chỉ cần a[i] lớn hơn a[j] là đổi chỗ ngay. Sau khi xong cả hai vòng, mảng đã sắp tăng dần.

Khác Selection Sort (Sắp xếp chọn): Interchange Sort đổi chỗ ngay khi phát hiện, còn Selection Sort chờ tìm được min rồi mới đổi một lần.

02 · Người trình bày 2

Khi nào nên dùng / không nên dùng

Đọc to

Interchange Sort phù hợp khi học thuật toán cơ bản, khi mảng rất nhỏ, hoặc khi cần đoạn code cực ngắn gọn, dễ nhớ. Vì logic đơn giản nên rất dễ viết và giải thích trên bảng.

Tuy nhiên không nên dùng với dữ liệu lớn vì O(n²). Cũng không phù hợp nếu cần tính ổn định, hoặc khi thao tác swap tốn kém – vì số lần đổi chỗ thường nhiều hơn Selection Sort.

✓ Phù hợp khi

  • Học thuật toán cơ bản
  • Mảng rất nhỏ
  • Cần code cực ngắn gọn

✗ Không phù hợp khi

  • Dữ liệu lớn
  • Cần ổn định
  • Swap (đổi chỗ) tốn kém
03 · Người trình bày 3

Thuật toán chi tiết

Đọc to

Bước 1: Cho i chạy từ 0 đến n−2. Mỗi i là vị trí đang được cố định dần.

Bước 2: Với mỗi i, cho j chạy từ i+1 đến n−1 – so sánh a[i] với mọi phần tử đứng sau.

Bước 3: Nếu a[i] > a[j], đổi chỗ ngay a[i] ↔ a[j]. Không chờ, không tìm min trước.

Bước 4: Lặp đến hết. Mảng đã sắp tăng dần. Tổng số lần so sánh khoảng n(n−1)/2.

1

Vòng ngoài

i: 0 → n−2

2

Vòng trong

j: i+1 → n−1

3

So sánh & Đổi

a[i] > a[j] → đổi ngay

4

04 · Người trình bày 4

Sơ đồ minh họa từng bước

Đọc to

Minh họa với mảng 5, 1, 4, 2, 8.

i=0 (giá trị 5): so với 1 → đổi thành 1,5,4,2,8. So tiếp với 4,2,8 thì 1 nhỏ hơn nên không đổi.

i=1 (giá trị 5): so với 4 → đổi; so với 2 → đổi; so với 8 không đổi. Mảng: 1,2,5,4,8.

i=2 (giá trị 5): so với 4 → đổi thành 1,2,4,5,8. i=3: 5<8 không đổi. Đã sắp xong. Mọi người có thể bấm nút bên dưới để xem từng bước.

05 · Người trình bày 5

Mã giả & Cài đặt C++

Đọc to

Mã giả rất ngắn: hai vòng for lồng nhau, bên trong chỉ một câu if đổi chỗ. Code C++ tương tự – ngắn, dễ nhớ. Tuy nhiên số lần swap thường nhiều hơn Selection Sort vì mỗi lần phát hiện sai thứ tự đều đổi ngay.

procedure InterchangeSort(a[0..n−1])
  for i ← 0 to n−2 do
    for j ← i+1 to n−1 do
      if a[i] > a[j] then
        swap a[i] with a[j]
      end if
    end for
  end for
end procedure
void interchangeSort(int a[], int n) {
  for (int i = 0; i < n - 1; i++) {
    for (int j = i + 1; j < n; j++) {
      if (a[i] > a[j]) {
        int temp = a[i];
        a[i] = a[j];
        a[j] = temp;
      }
    }
  }
}
Vòng ngoài i: cố định vị trí đang xét
Vòng trong j: so sánh với phần tử phía sau
Đổi chỗ ngay: khi a[i] > a[j]
Số lần swap: thường nhiều hơn Selection Sort

Ưu điểm

Đọc to

Interchange Sort rất dễ hiểu và dễ cài đặt, code ngắn gọn, phù hợp giảng dạy. Không cần bộ nhớ phụ – sắp xếp tại chỗ O(1). Logic rõ ràng nên học sinh dễ nhớ và dễ viết lại trên bảng.

  • Rất dễ hiểu và cài đặt
  • Không cần bộ nhớ phụ (in-place / tại chỗ)
  • Phù hợp giảng dạy khái niệm cơ bản
  • Code ngắn gọn, dễ nhớ
08 · Người trình bày 8

Nhược điểm

Đọc to

Độ phức tạp O(n²) khiến thuật toán chậm với dữ liệu lớn. Số lần đổi chỗ thường nhiều hơn Selection Sort. Không ổn định. Hiệu suất kém nên ít dùng trong hệ thống thật – chủ yếu dùng để minh họa trong giáo dục.

  • O(n²) – chậm với dữ liệu lớn
  • Số lần đổi chỗ nhiều hơn Selection Sort
  • Không ổn định (unstable)
  • Hiệu suất kém trong thực tế

Kết luận

Đọc to

Tóm lại, Interchange Sort (Sắp xếp đổi chỗ) đơn giản nhưng không hiệu quả với dữ liệu lớn. Nên học để hiểu cơ chế đổi chỗ, sau đó chuyển sang thuật toán tốt hơn. Có thể áp dụng với mảng rất nhỏ dưới 20 phần tử.
